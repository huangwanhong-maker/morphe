## Acyclic Relations, and What Follows from Several Things Together

morphe now reads a relation given as arcs as an order ([decision 0015](../decisions/0015-acyclic-relations-and-forward-chaining.md)).

- One can ask whether a relation has a cycle, and is shown the cycle when it has.
- One can ask what lies before or after an element, with the least number of steps to each, and to a bound.
- One can take the covering relation: the fewest arcs with the same order.
- One can gather a relation by classes, each arc between two classes with how many arcs it stands for.
- For rules with several premises and one conclusion, one can find everything that follows from a set of givens, and what rests on one of them: what is no longer had once it is withheld.

It was written for the infrastructure's history domain, where one object's appearing rests on others; nothing in it names history.
