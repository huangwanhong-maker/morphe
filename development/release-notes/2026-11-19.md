# Release Notes: 19 November 2026

## Blocks, Cut Vertices and Bridges

A graph can now be split into its blocks ([decision 0020](../decisions/0020-blocks-cut-vertices-and-bridges.md)). Each block is a maximal part that stays connected when any one vertex is removed. The split also names the vertices whose removal disconnects the graph (its cut vertices) and the edges whose removal does (its bridges), in one pass by Hopcroft and Tarjan's method. Each answer is checked against removal itself: on random multigraphs, deleting a vertex or an edge separates the graph exactly when the method says it does.

The first use is the infrastructure's diplomacy domain, which asks whether an undertaking among many parties can continue without a particular coordinator.
